# Ndähi — Un aire más limpio, una vida mejor

Sitio institucional de la iniciativa comunitaria **Ndähi**, nacida en el Bajío, México, para impulsar hogares con menos humo mediante estufas ecológicas tipo Patsari y trabajo conjunto con las familias.

## Tecnologías

- HTML, CSS y JavaScript (sin framework ni compilación).
- Diseño adaptable a móviles y escritorio.
- Paleta oficial: `#132E29`, `#E7A45D`, `#F8F6EC`.
- Recursos de identidad: `assets/logo-ndahi.jpg`, `assets/favicon.png` y `assets/favicon.svg`.
- Fotografía documental de la cocina: `assets/contexto-cocina.jpg`.

## Ejecutar en local

Clona este repositorio y abre `index.html` en tu navegador. Como alternativa:

```bash
python3 -m http.server 8000
```

Luego visita `http://localhost:8000`.

## Publicar en GitHub Pages

1. Abre **Settings → Pages** de este repositorio.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Selecciona **main** y **/(root)**; después haz clic en **Save**.
4. Cuando termine la publicación, visita **https://byteshark-dev.github.io/ndahi/**.

Las rutas del sitio son relativas, compatibles con GitHub Pages.
